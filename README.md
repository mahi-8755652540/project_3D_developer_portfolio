## 🤖 Introduction

This project is a **3D Developer Portfolio Website** created to showcase my skills, projects, and experience using modern frontend technologies.

It focuses on:
- Clean UI & responsive design  
- Smooth animations  
- Interactive 3D components  
- Professional, recruiter-friendly presentation  

This portfolio can be used for **jobs, freelancing, and personal branding**.

---

## ⚙️ Tech Stack

- **React.js**
- **Three.js**
- **React Three Fiber**
- **React Three Drei**
- **Framer Motion**
- **Tailwind CSS**
- **Vite**
- **EmailJS**

---

## 🔋 Features

👉 **3D Hero Section**  
Interactive 3D elements with smooth camera movement.

👉 **Animated Sections**  
Framer Motion animations for modern user experience.

👉 **3D Skills Showcase**  
Technologies displayed using 3D geometries.

👉 **Projects Section**  
Animated project cards with clean UI.

👉 **Contact Form with EmailJS**  
Users can directly send emails from the website.

👉 **Responsive Design**  
Works perfectly on desktop, tablet, and mobile.

👉 **Reusable Code Structure**  
Clean and scalable architecture.
